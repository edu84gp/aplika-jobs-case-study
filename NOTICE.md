# Aviso de alcance y titularidad

## Qué es este repositorio

Este es un caso de estudio técnico de Aplika Jobs. Documenta el problema, la arquitectura, las decisiones y una selección de fragmentos con el objetivo de demostrar la aportación profesional de Eduardo García Prieto.

## Qué no contiene

- El código completo del producto.
- El esquema real de la base de datos.
- Los prompts internos, pesos o reglas propietarias del sistema de matching.
- Claves, tokens, variables de entorno o cadenas de conexión.
- Datos de usuarios reales.
- El panel de administración.
- El repositorio privado de Aplika Jobs como submódulo o enlace de acceso.

## Titularidad

Aplika Jobs es un proyecto en equipo desarrollado por Eduardo García Prieto y Roberto Antonio López. La marca, el producto y el código completo pertenecen a sus autores.

El texto, la selección de fragmentos y las capturas de este repositorio se publican como demostración profesional. No se concede una licencia de uso sobre el producto.

## Sobre las capturas

Las capturas muestran la superficie pública de la demo. Las tarjetas del panel son datos de ejemplo y las cifras de la landing son mensajes de producto, no métricas verificadas.

## Acceso al código privado

No se ofrece acceso de solo lectura al repositorio privado. GitHub solo permite conceder escritura a colaboradores en repositorios privados de cuentas personales. Este caso de estudio es la vía pública para revisar la aportación técnica sin exponer propiedad intelectual.
